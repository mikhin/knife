# Требования

- Вход — простыни markdown на английском. Файл режется на чанки и растворяется во вселенной проекта, сам нигде не хранится
- Чанк — id, project, текст. Режем по точкам, `;`, `:`, таблицы — как обычный текст. Чанки лежат кучей, без порядка
- Чанк не правится: только удалить без возврата или завести новый
- Токенизация до слова: формы одного слова — одно слово. Граф показывает, что с чем связано
- Анти-слоп: дубли (насколько похожи и какие слова совпали), вода (какое правило сработало), висящие куски. Инструмент показывает, удаляю я
- Дубли — по всей вселенной, между файлами разных лет. Порог похожести крутится
- Поиск по словам. Клик по слову — связи и все вхождения. Переход граф ↔ текст
- Кроме текста не хранится ничего: дубли, вода, вхождения, связи, замечания линтеров считаются на месте и живут только на фронте. В базе две таблицы — `projects` и `chunks`
- Фуллстек без ИИ. Postgres. Vale, textlint, proselint — в Docker на бэке, результат сразу на фронт. Своих словарей не писать
- Вселенная — десятки тысяч чанков. Граф и дубли без ожидания минутами
- Цель — чтобы через пять лет люди и агенты ориентировались в требованиях
